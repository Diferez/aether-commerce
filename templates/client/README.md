# Client Store

This is a client implementation shell. Add branding, assets, custom pages and
business-specific adapters here; consume versioned `@aether/*` packages for
commerce behavior. Configure the GitHub Packages registry before `pnpm install`,
then run `pnpm typecheck` and initialize Git with `git init`.

Never put provider secrets in `config/`; runtime secrets belong in the chosen
deployment platform's secret manager.
